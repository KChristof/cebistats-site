La section Résultats est celle que le jury lit avec le plus d’attention, souvent tableau par tableau. Quelques règles simples la rendent claire et évitent les questions embarrassantes.

## Suivre l’ordre des objectifs

Les résultats répondent aux objectifs, dans le même ordre. Une organisation classique :

1. **Diagramme de flux** : nombre de dossiers ou de sujets éligibles, exclus (avec les raisons) et inclus.
2. **Caractéristiques de la population** (le « tableau 1 »).
3. **Résultats de l’objectif principal.**
4. **Résultats des objectifs secondaires.**
5. **Analyse multivariée**, le cas échéant.

## Le tableau 1

Il décrit la population étudiée :

- variables quantitatives : moyenne ± écart-type si la distribution est symétrique, sinon médiane [intervalle interquartile] ;
- variables qualitatives : effectif et pourcentage, **n (%)** ;
- donnez toujours le **dénominateur** quand il varie à cause des données manquantes.

## Les chiffres

- Gardez un nombre de décimales cohérent : une décimale pour les pourcentages, pas « 33,3333 % ».
- Avec moins de 50 sujets, les pourcentages peuvent induire en erreur : « 2 patients sur 5 » est plus honnête que « 40 % ».
- En français, la virgule est le séparateur décimal : 2,1 et non 2.1.

## Les valeurs de p

- Donnez la valeur exacte (p = 0,032) plutôt que « p < 0,05 », sauf pour les très petites valeurs : écrivez p < 0,001.
- Précisez le test utilisé, en note du tableau ou dans la méthodologie.
- Une valeur de p ne mesure pas l’importance d’un effet. Accompagnez-la de la mesure d’association et de son intervalle de confiance : « OR = 2,1 ; IC 95 % : 1,3–3,4 ; p = 0,003 ».

## Ne pas répéter les tableaux dans le texte

Le texte met en avant l’essentiel, il ne recopie pas les cellules. Préférez « La mortalité à deux ans était plus élevée chez les patientes de stade III–IV (tableau 3) » à une énumération de tous les pourcentages.

## Choisir la bonne figure

| Message | Figure |
|---|---|
| Répartition d’une variable qualitative | Diagramme en barres (évitez les camemberts à plus de 4 parts) |
| Distribution d’une variable quantitative | Histogramme ou boîte à moustaches |
| Évolution dans le temps | Courbe |
| Survie | Courbe de Kaplan-Meier avec effectifs à risque |
| Résultats d’une régression | Forest plot |

Une figure doit pouvoir être comprise seule : titre explicite, axes nommés avec leurs unités, légende, effectif.

## Pas d’interprétation dans les résultats

Les résultats décrivent ce qui a été observé. Les comparaisons avec la littérature, les explications et les limites appartiennent à la discussion.
